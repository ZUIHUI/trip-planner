# Project instructions

## Design source of truth

- Before changing any frontend UI, component, layout, style, typography, color, image treatment, or visual asset, read the root `DESIGN.md` completely.
- Treat `DESIGN.md` as the source of truth for design tokens, typography, spacing, radius, hierarchy, contrast, responsive behavior, and interaction styling.
- Keep text placed over photos reliably readable by using the documented on-dark text colors and an atmospheric dark scrim.
- Desktop navigation labels use the documented body-small scale (14px); small section labels use the micro scale (11px).
- User-facing itinerary dates use a date plus an English abbreviated weekday, such as `10/25 Wed.`. Do not show generic `Day N` or `第 N 天` labels when a date is available.
- Before releasing frontend changes, run the repository's syntax, debug-marker, test, and production-build checks.
