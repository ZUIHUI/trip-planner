Trip Planner mockup v3

市面產品參考後的全頁面 UI mockup

把目前 app 的登入、旅程列表、行程詳情所有 tab 與浮層整理成一套可視化產品板。方向參考 Wanderlog 的地圖行程同屏、Tripsy 的資訊集中與權限/費用、Polarsteps 的旅程地圖與回憶感。

參考產品語言

Wanderlog
Map + itinerary Tripsy
All details Polarsteps
Journey map
Map-first今日旅途與桌面模式先看到路線、地點、下一站，再進入表單或清單。
Calm operations用短狀態、chip、卡片層級讓大量功能不吵，適合旅行中快速掃描。
Group-ready旅伴在線、權限、邀請碼、同步衝突都有固定位置，而不是臨時提示。
AI as assistAI 是可召喚的旅程助手，輸出能直接加入想去或排進 Day timeline。
